# 堇子扩展规则 · 当前试行规则

更新日期：2026-10-05。本文记录本轮确认的规则与实现边界，玩家版说明见 [乘车须知](../public/rules.html)。时长、次数和概率作为当前试玩参数，尚未经过平衡验证。

## 1. 人数、外观与胜负

支持3–6人：莲子、梅莉、紫各1人，另有0–3名堇子。所有玩家独立移动与操作。棕色外观为莲子和堇子，紫色外观为梅莉和紫；颜色表示外观组，不表示胜利阵营。莲子的玩家身份公开，梅莉与紫隐藏身份。

| 角色 | 胜利条件 |
| --- | --- |
| 莲子、未侵蚀梅莉 | 两人实际停靠同一站，秘封获胜。 |
| 紫、已侵蚀梅莉 | 紫或已侵蚀梅莉与真正的莲子实际停靠同一站，紫方获胜。 |
| 全体堇子 | 秘封获胜，且截至结算时至少一名堇子从未被真正的紫抓到，则包括曾被抓到者在内的全体堇子共同获胜。 |

堇子不再逐人判定胜负，不计算贡献分。只要还有一名未被真正的紫抓到，所有堇子都保有分享秘封胜利的可能；被抓者仍可主动协助其他人。全部堇子被抓不会提前结束游戏，也不公开公告。紫方胜利或超时，堇子均不获胜；技术中止属于对局未完成。

梅莉的侵蚀仍为永久效果，不增加净化、逃脱或其他胜利条件。梅莉被侵蚀后，秘封会合的胜利条件不再可达；她改为协助紫，其他玩家仍按已有规则继续对局。京都庇护不能治疗已经发生的侵蚀。

## 2. 紫色接触与两项隐藏状态

每名堇子分别记录“能否再次接帽”和“是否曾被真正的紫抓到”。两项状态独立保密，游戏中不直接通知玩家，赛后揭晓。

| 实际停靠同站的对象 | 再次接帽能力 | 抓捕记录 | 当刻持帽时 |
| --- | --- | --- | --- |
| 梅莉，包括已侵蚀梅莉 | 永久失去 | 保持原状 | 帽子立即归还莲子 |
| 真正的紫 | 永久失去 | 永久记为已被抓到 | 帽子立即归还莲子 |

一名紫色角色同时遇到多名堇子时，逐人结算。先遇紫再遇梅莉不会恢复状态；同刻遇到两名紫色角色时取全部效果，但帽子只归还一次。梅莉即使被侵蚀也不获得真正紫的抓捕效果。因此，被梅莉封锁接帽、却从未被紫抓到的堇子仍能维持全体堇子的获胜可能。

这类接触沿用原有停站口径：终点、途中实际停靠和留站均可构成同站；不停站通过、区间擦肩、线路交叉、同城不同站均不构成会合、捕获或封锁。帽子接触的口径另见下一节，不扩大紫色角色的捕获范围。

堇子不出局、不转为观战者。无论隐藏状态如何，她都继续移动、抽线、选路、改签、途中下车、留站和讨论，继续计入必要确认和断线暂停。目标文案、基础头像、普通操作和网络状态不因被抓而改变。

系统不公开“已被抓”“还能否接帽”或剩余未被抓人数。帽子提前归还是允许的线索，两名紫色角色造成的归还表现相同。玩家可以结合身份、实际相遇、连续未换帽等现象推理；规则保证不直接泄露隐藏状态，不保证玩家永远无法推测。

## 3. 莲子与堇子的真实接触

莲子和堇子在同一结算时刻真实停靠或通过同一个游戏节点，构成换帽接触。两方对称：莲子到达等待中的堇子、堇子到达等待中的莲子、两人同时到达或不停站通过，都按真实节点位置判断，不要求其中任何一人结束整段行程。

过去的地图目击重合、相邻不同站、区间擦肩和没有收录的现实车站均不算接触。仅堇子与堇子相遇不会触发接触结果暂停；她们的公开标记仍按匿名地图规则聚合。

按“莲子—某名堇子”这一对记录接触。一次持续接触只处理一次，不因同站等待、时间推进或重复点击确认重新抽签。两人分离后再次真实相遇，才算一次新接触。若新堇子加入同站人群，新配对可触发一次新事件，原有持续接触的配对不会重新参与抽签。

## 4. 自动换帽、暂停与确认

全场只有一顶帽子，初始由莲子持有。取消“不使用”“指定堇子”“随机堇子”等手动预设。每次新的莲子—堇子接触自动进行如下处理：

1. 本刻只有一名新接触堇子时，选择她；同时有多名时，从本次新接触的堇子中等概率选择一名。选择时不按隐藏资格过滤。
2. 检查帽子是否仍在莲子手中、目标是否能接帽、是否已结束冷却、是否仍有成功次数。
3. 全部条件满足时，以50%概率换帽；条件不满足或概率失败都不换帽，不寻找替补、不重抽其他人。
4. 无论结果与失败原因如何，都触发相同的接触暂停。整组接触参与者在自己的手机上查看个人结果并确认；未被抽中的参与者也需确认，持续接触的旧配对不因此再抽签。

参与者只收到如实的个人成功结果或统一的“本次未换帽”，不显示“资格已封锁”“冷却中”“次数不足”“没有被抽中”等失败原因。成功时莲子与实际接帽者知道交接结果；没有接到帽子的堇子不会被告知虚假的成功，也不会获知另一名堇子的私密结果。

无论是否真正停靠、是否成功换帽，都暂停游戏时间和全部行程。接触暂停只是等待确认，不把不停站通过变成实际停站，不提供换乘或改选终点的机会，也不更新梅莉的真实莲子停站记录。确认后各自继续原行程；正常到达终点者另按正常规则选路。

如果接触与终点到站、留站到期等发生在同刻，将接触结果确认和必要选路合入一个决策批次。每名玩家完成自己所有待办后才算就绪，全部必要确认完成后才允许继续。主持人可为未选路者安排留站，但不能代替或绕过任何人的接触确认。

公共界面只显示统一的暂停与待确认人数，不公开接触者的姓名、座位、换帽结果或失败原因。人数按仍有待办的玩家计算，同一人同时需要选路与接触确认也只计一人。不同结果采用相同的公开提示和匿名地图行为；玩家现实中的发言与操作速度仍可能成为推理线索。

## 5. 时长、次数与立即归还

| 参数 | 当前值 |
| --- | --- |
| 符合全部条件后的换帽概率 | 50% |
| 单次戴帽时长 | 最多8刻，即2游戏小时 |
| 莲子全局成功次数 | 每局2次，所有堇子共用；失败不扣次数 |
| 归还后冷却 | 4刻，即1游戏小时 |
| 同时持帽的堇子 | 最多1名 |
| 主动召回或转交 | 均不允许 |

一刻固定为15游戏分钟；选路、接触确认和技术暂停均不消耗借戴时间或冷却。18:00成功借帽且未提前归还时，20:00到期，成功当刻不立即扣掉一刻。

自然到期，或戴帽堇子与梅莉、紫实际停靠同站时，帽子立即归还莲子，从该刻开始冷却，成功次数不返还。梅莉是否侵蚀不影响这个效果。接触发生时即归还，不等玩家确认才归还。

归还清除原借戴的到期事件。若18:30提前归还，冷却到19:30；原定20:00不再产生第二次归还。自然到期与紫色接触同刻、或两名紫色角色同时接触时，只归还一次、启动一次冷却。重复接触已经无帽的堇子不刷新冷却。

帽子归还会重新提供辨认莲子的线索，这是借帽的代价。如果莲子与其他棕色角色仍然重合，地图只显示聚合点中有人戴帽。若莲子在区间中，帽子显示在她最近一次公开目击标记上，不因此公布实时位置。

帽子不改变真实角色、会合与捕获规则。紫抓到戴帽堇子不会直接赢得对局；无帽莲子仍会被紫抓到，也仍能与未侵蚀梅莉会合。

## 6. 地图与梅莉的历史停站记录

公开地图显示全体角色的最近站点目击：1–4个棕色角色、2个紫色角色。莲子首次接触堇子之前，棕色头像带临时字母，目击列表附座位与昵称；首次接触后（不论是否换帽），棕色头像只区分有帽和无帽，不附字母、姓名、座位或可追踪回玩家的固定标识；紫色头像可标座位，但不区分梅莉与紫，侵蚀不变色。角色美术仍使用现有占位资源，新头像完成后通过素材入口替换。

棕色角色在同一时刻真实交会时聚合显示；离站后按匿名分支拆分，不直接把新分支对应回旧玩家。无论是否换帽，聚合、拆分和历史时间处理均一致。首次接触后，公开列表、历史、日志与悬浮提示遵守相同限制；不能通过另一处界面重新关联棕色座位与位置。

玩家名单可显示座位和昵称，莲子玩家身份仍公开，但名单不能与她的匿名地图分支绑定。同站匿名不消除所有推理：行程时刻、留站状态、交流与帽子归还都可能帮助判断。

除莲子本人外，系统只向梅莉额外提供真实莲子上一次实际停靠的站名与时刻。开局以起点为初始记录，终点到站和途中实际停靠会更新；不停站通过以及为换帽确认而暂停都不更新。记录不附离站状态、方向、区间进度、下一站、目的地或到达预测。

这项能力不受换帽和侵蚀影响。梅莉被侵蚀后仍可查看并口述给紫，但紫不会自动得到该私密信息。所有玩家仍能查看自己的实时行程；可以自由口述或说谎，不能展示手机证明身份或系统结果。

## 7. 普通选路与留站

保留抽线、改签、自由选择沿线终点、途中申请下一站下车，以及本人选路时留站30分钟。普通行程一经提交即锁定，不能因其他人提出要求撤回。

删除系统“请求留站”动作、接受/拒绝弹窗和每局一次额度。希望另一人留站时，玩家口头协商；对方在自己仍可选路的阶段自行选择留站或线路。口头请求不改变已锁定行程，不额外生成待办、暂停或权限。

## 8. 同刻结算与判例

同刻沿用先离站、后到站的站位结算，不把站台擦肩当成相遇。先处理堇子与紫色角色的真实停靠接触及强制归还，再判断核心胜负；未侵蚀梅莉与莲子同时会合仍优先秘封胜利。

若继续游戏，处理原有站点事件与侵蚀（京都庇护先于侵蚀）、仍有效的帽子自然到期，再处理本次新的换帽接触。刚被封锁的目标不接帽，刚归还的帽子受冷却限制，失败仍走接触确认。最后合并选路与接触待办，等待必要确认。对局已经结束时直接展示结局，不再要求后续接触确认。

| 情景 | 结果 |
| --- | --- |
| 莲子不停站经过A，堇子实际在A | 形成新接触，按条件判50%，无论成败都暂停确认，莲子原行程不变。 |
| 堇子到达A，莲子正在A留站 | 同样处理新接触；不限于莲子主动到达。 |
| 两人在同一区间擦肩，或只剩旧目击都显示A | 不产生换帽接触。 |
| 莲子与堇子确认后仍持续同站 | 不重复暂停或重抽。 |
| 已有莲子与甲持续接触，乙加入 | 只把乙作为新接触候选，甲不重抽；接触整组查看各自结果并确认。 |
| 三名新堇子同刻相遇，其中抽中的一名已失去接帽能力 | 本次不换帽，不换选其他人；参与者照常确认，不公布失败原因。 |
| 戴帽堇子实际停靠遇到梅莉或紫 | 立即归还，永久失去接帽能力；只有真紫接触写入抓捕记录。 |
| 两名堇子已被紫抓，第三名从未被紫抓，随后秘封会合 | 三名堇子共同胜利。 |
| 仅剩一名未被抓堇子，与莲子、未侵蚀梅莉、紫同时停靠 | 先记她被抓，再按会合优先判秘封胜；全体堇子已被抓，因此堇子集体不胜。 |
| 莲子18:00停靠A，18:30不停站经过B并暂停换帽确认 | 梅莉仍只看到“A · 18:00”，不获知莲子是否离站或正在B。 |
| 玩家已提交行程后，有人要求她留站 | 只能口头协商下一次选路，当前锁定行程不撤回。 |

累计恰好48小时时仍能结算相遇；下一刻超过48小时直接超时，不继续处理到站或换帽。无堇子的三人局没有换帽接触与确认，莲子始终持帽；其余外观分组、历史停站、会合、侵蚀与超时规则照常。

试玩应分别记录3–6人胜率、换帽成功率、接触暂停频率及等待时长、帽子归还后追踪效果，以及堇子采用“有人远离紫保底、其余人协助诱敌”分工时的参与感。梅莉永久侵蚀后其他角色的体验、接帽能力过早耗尽和失败带来的推理线索也应保留在复盘中。
